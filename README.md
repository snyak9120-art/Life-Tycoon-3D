# LIFE TYCOON 3D

A menu-driven 3D business tycoon prototype for Android, built with Godot 4.4.

## Current prototype
- Fixed 3D business skyline (no joystick and no open-world map)
- Business purchasing and upgrades
- Starting capital: Rp 25.000.000
- Passive business income
- Offline earnings capped at 7 days
- Local save data

## Build
Open the project in Godot 4.4, configure Android export templates and Android SDK, then export a debug APK.

This repository is an early playable prototype foundation, not a finished commercial game.
